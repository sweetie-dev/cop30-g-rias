# 🌿 COP30 em Belém do Pará

> Um projeto desenvolvido para apresentar a COP30 em Belém e valorizar a cultura e a identidade paraense através de suas gírias e expressões.

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de apresentar a COP30 e destacar a cultura paraense, trazendo algumas das expressões e gírias presentes no dia a dia do povo do Pará.

A proposta é unir tecnologia, informação e cultura regional em uma experiência visual e interativa.

## ✨ Funcionalidades

- Informações sobre a COP30
- Apresentação de gírias e expressões paraenses
- Exemplos em vídeo
- Carrossel interativo
- Seção sobre Belém como sede da COP30
- Design responsivo

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
